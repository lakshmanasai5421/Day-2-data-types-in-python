01
Numeric Data Types

Numeric data types are used to store numbers in Python. There are three kinds.

int

Integer

Stores whole numbers without any decimal point. Can be positive or negative.

  • No decimal
  • Positive or Negative
  • Unlimited size
# Example c = 1000 print(type(c)) # Output <class 'int'>
float

Float

Stores numbers with a decimal point. Used when precision is needed.

  • Has decimal
  • Positive or Negative
  • Scientific notation
# Example height = 5.9 print(type(height)) # Output 5.9 <class 'float'>
complex

Complex

Stores complex numbers. Mainly used in scientific and engineering calculations.

  • Real part
  • Imaginary part (j)
  • Scientific use
# Example x = 2 + 3j print(x) print(type(x)) # Output (2+3j) <class 'complex'>
02
String Data Type (str)

A string stores text or characters. It is written inside quotes and can contain letters, numbers, and symbols.

  • Written in quotes
  • Can hold letters, numbers, symbols
  • Immutable (cannot be changed)
  • Supports indexing
# Example name = "Python" print(name) # Output Python
Names Addresses Messages Usernames
03
Boolean Data Type (bool)

A boolean stores only two values: True or False. It is used for decisions and conditions.

  • True
  • False
  • Used in conditions
print(10 > 5) print(10 < 5) # Output True False

Real world situations where boolean is used:

Login success Exam pass or fail Payment completed Is admin Is active
04
Sequence Data Types

Sequence types store multiple items in an ordered manner.

list

List

Stores multiple items in one variable. Items can be added or changed.

  • Ordered
  • Mutable
  • Allows duplicates
  • Syntax: []
students = ["Sai", "Ravi", "Kiran"]
Student names Product list Marks list
tuple

Tuple

Like a list but cannot be changed after creation. Faster than list.

  • Ordered
  • Immutable
  • Faster than list
  • Syntax: ()
colors = ("Red", "Blue", "Green")
Fixed data Coordinates Days of week
array

Array

An array stores elements of the same data type together. Used for fast numerical operations and to reduce memory usage.

from array import array numbers = array('i', [10, 20, 30, 40]) print(numbers) # Output array('i', [10, 20, 30, 40]) # Modify an element numbers[1] = 50 print(numbers)
Type Code Data Type
'i'Integer
'f'Float
'u'Unicode character
05
Set Data Type (set)

A set stores unique values only. Duplicate values are automatically removed.

  • Unordered
  • No duplicates
  • Mutable
  • Syntax: {}
a = {1, 2, 2, 3} print(a) # Output {1, 2, 3}

Real world uses of set:

Unique IDs Unique usernames Removing duplicates
06
Dictionary Data Type (dict)

A dictionary stores data as key-value pairs. You access a value by its key instead of a position number.

  • Key-value structure
  • Fast data access
  • Mutable
  • Keys must be unique
# Syntax my_dict = { "key1": "value1", "key2": "value2" } # Accessing a value print(student["name"])
Student records Employee details User profiles
